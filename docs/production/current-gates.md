## Separate decision rules

The plan's **ten engineering-day transport exit rule** applies only to safe transport qualification: if there is no observed safe launch, inspect, goal, and supervision path by then, stop that implementation attempt, document the capability boundary, and proceed with attended product delivery. It is not a 14-day soak, an inference allowance, or a waiver of native delivery gates.

The **14-day / 20-accepted-outcome cohort** measures sustained product performance after usable delivery exists. It does not close human calibration, source/installed checks, real native supervision, or publication authority by itself.

Owner review, source publication, package release, provider activation, deployment, and live-product operation remain distinct authority and evidence gates. Report each only when its own retained evidence exists.
