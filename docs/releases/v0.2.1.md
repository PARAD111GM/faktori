# Faktori v0.2.1

Experimental patch release adding safe stale coordinator-lock recovery to the
installable download. Includes all v0.2.0 features.

- `faktori backup inspect-lock <absolute-journal-path>` reports owner visibility
  and an exact inspection token without modifying records.
- `faktori backup recover-lock <recovery-request.json>` preserves stale-lock
  evidence before removal and requires confirmed owner absence, unchanged
  identity and explicitly quiesced admission.
- Shared ownership guard serializes recovery, Console startup and backup lock
  acquisition. Live, unknown, malformed or changed ownership is refused.
- Backup errors now point to inspection and documented recovery steps.

Stop older runtimes and their automatic restarts before recovery; they do not
honor the new ownership guard. This update does not stop workers, recover live
installations automatically, activate integrations or change provider access.

See the [maintenance guide](https://github.com/PARAD111GM/faktori/blob/v0.2.1/docs/maintenance/README.md)
for the recovery request and safe update prerequisites. The original v0.2.0
download is unchanged.
