# v0.2.6 — requirements discovery and product execution handoff

A raw idea can now begin an attended interview, retain sourced owner answers and
model proposals separately, and resume from immutable local history. Accepted
product definitions compile into scoped context and the existing Lean execution
loop after explicit execution and release bindings are supplied.

The handoff carries complete inherited constraints, exact definition/request file
digests, one full-feature acceptance command, web/iOS/Android release contracts,
and existing-product baseline compatibility. Native mobile defaults to a shared
codebase. Missing bindings remain actionable; an execution configuration does
not establish deployment or production acceptance.

Product operations inspection covers security, data policy, backup/restore,
incident ownership, recovery, limits and platform resources. The append-only
intervention ledger rejects conflicting retries, malformed history and file
aliases. Product artifact execution preflight resolves paths to keep the two
compiler-owned files inside the approved workspace.

## Validation and update

Use Node 24/npm 12. The added `npm run accept:production` exercises the full local
CLI slice using explicitly synthetic decisions and disposable files. Testing
instructions now require minimal full-feature validation and no micro-unit
testing loops. Verification results are recorded in the implementation status;
this source change does not claim an executed provider/deployment journey.

Existing factory state needs no migration. New discovery histories and
intervention ledgers are opt-in local JSONL artifacts: retain their original
bytes, canonical paths and references for resume. Rebuild/reinstall the package
to obtain the new CLI commands. No hosting resources or provider authentication
are created or modified by these preparation commands.
