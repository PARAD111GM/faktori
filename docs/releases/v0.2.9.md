# v0.2.9 — sourced product-definition drafts

Requirements interviews now provide a complete proposal-only definition prompt
and an import handoff bound to the exact immutable session. The definition
preserves owner intent, web/native targets and existing-product baseline context.
It includes linked requirements and positive, negative and recovery scenarios.

The importer retains exact response-byte provenance and separates source links
from verified interpretation. Model output cannot create owner decisions, accept
requirements, fabricate observed constraints or grant execution/release authority.
Unknown and superseded interview answers cannot become owner evidence.

Update the installed package before using `discovery definition-prompt` and
`discovery import-definition`. This source increment does not close hosted
delivery, native distribution, live-product acceptance or automation qualification.
Observed source/installed/native results are recorded in
[execution status](../production/execution-status.md).
