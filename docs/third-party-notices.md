# Skill design references

The Faktori skill kit uses original, project-specific procedures. The debugging,
verification, and review-feedback procedures draw on patterns reviewed in
[Superpowers](https://github.com/obra/superpowers), local reference version 6.3.0:
`systematic-debugging`, `verification-before-completion`, and
`receiving-code-review`. Superpowers is optional, not a runtime dependency.

Adaptations retain Faktori's configurable authority, proportional evidence,
provider neutrality, and secret-safe diagnostics. Upstream examples that print
environment or credential values are not included. A diagnostic hypothesis is
not permission to rewrite architecture, and an upstream mandatory review loop
does not override the owner's review policy.

The named Skill Creator process guided authoring: concrete examples, reusable
resources, initialization of new skills, imperative procedures, progressive
disclosure, packaging validation, and iteration from observed behavior. No
personal skill installation is required to consume the resulting public kit.
