# Build

Inputs are the context packet, accepted plan/design, dependency contracts, and execution authority. Output the smallest scoped diff plus tests or verification notes; compact, normal, and high-risk packaging follows the contract. Do not broaden authority or overwrite user edits. Evidence names the exact source revision, changed paths, commands, and observed results. Escalate missing context, blocked dependencies, credential requests, unexpected scope, or unsafe recovery state.
