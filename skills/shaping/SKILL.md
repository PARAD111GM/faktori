# Work shaping

Inputs are product intent, constraints, acceptance criteria, design references, and known dependencies. Output stable nodes with primary parents, typed planning/executable distinction, and explicit dependency contracts. Use compact for a bug/chore, normal for a feature, and high-risk for broad or irreversible change. Completion evidence is the node graph, source revisions, criteria, and a context packet that excludes unrelated siblings. Escalate cycles, missing parent authority, ambiguous criteria, or dependencies that cannot be contracted.
