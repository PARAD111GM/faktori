# Test

Inputs are criteria, context, diff revision, risk level, and environment. Output observed test results, acceptance notes, and inapplicable-stage reasons. Select compact verification for a small bug, normal coverage for a feature, and high-risk failure/recovery and security evidence when warranted. Completion evidence includes command or interaction, exact revision, environment, authority, and result—not a checkbox or process exit alone. Escalate flakes, missing receipts, failed criteria, or unavailable required environments.
